SELECIONANDO os elementos DOM

posso selecionar os elementos DOM por marca(tangente); por ID; por classe; por seletor (por CSS).

existem algums comandos que nós vamos utilizar

Por marca (tangente)

O comando é o getElementByTagName

está no plural; getElemts... eu preciso dizer o número do elemento que eu quero utilizar , lembrando que no JS, a contagem dos elemtos começa do zero.

Por Id

O comando é: getElementByID

Preciso atribuir um ID na tag que eu quero manipular.

Por ClassName

O comndo é o: getElementsByClassName

Por seletor de CSS

O comando é querySelector

se a tag que eu quero selecionar estiver com um id, eu uso
